# Audio Files

## Om Chanting Background Sound

To enable the Om chanting background sound in the chants modal, you need to add an audio file here.

### Required File:
- **Filename:** `om-chanting.mp3` or `om-chanting.ogg`
- **Content:** Peaceful Om chanting with temple bells
- **Loop:** Yes (should loop continuously)
- **Duration:** 30-60 seconds (will loop)

### Where to Get Om Chanting Audio:

#### Free Options:
1. **Pixabay** - https://pixabay.com/sound-effects/search/om/
   - Free for commercial use
   - No attribution required
   - Search for "om chanting" or "temple bells"

2. **Freesound** - https://freesound.org/
   - Search "om mantra" or "meditation bells"
   - Check license (CC0 or CC-BY)

3. **YouTube Audio Library** - https://studio.youtube.com/
   - Free background music
   - Search "meditation" or "om"
   - Download and convert to MP3

### How to Add:
1. Download an Om chanting audio file
2. Save it as `om-chanting.mp3` in this `audio/` folder
3. The chants modal will automatically play it when opened

### Format:
- MP3 (recommended) - works on all browsers
- Or OGG - alternative format

Once added, users will hear peaceful Om chanting with bells when viewing chants in the modal!
