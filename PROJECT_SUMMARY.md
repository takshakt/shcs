## 🎨 Design System

### Modern, Minimalistic Aesthetic
- **Clean Typography**: Poppins for headings, Inter for body text
- **Consistent Spacing**: 8px base unit, predictable rhythm
- **Professional Color Palette**: Based on SHCS orange (#FF6600)
- **Responsive Design**: Mobile-first approach, works on all devices
- **Modern Components**: Cards, buttons, forms, hero sections

### CSS Architecture
- **reset.css**: Normalizes browser defaults
- **variables.css**: All design tokens in CSS custom properties
- **base.css**: Typography, containers, grid system, utilities
- **components.css**: Header, nav, buttons, cards, forms, footer
